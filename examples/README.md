# Examples

This directory contains example code demonstrating how to use the AI Music Tagger.

## Files

- **basic_usage.py** - Simple example of processing a single audio file
- **batch_processing.py** - Process multiple audio files at once
- **no_llm_usage.py** - Use the pipeline without an OpenAI API key (rule-based fallback)
- **example_output.json** - Sample JSON output showing the metadata structure

## Running the Examples

Make sure you've installed the dependencies first:

```bash
pip install -r requirements.txt
```

### Basic Usage

```bash
python examples/basic_usage.py
```

This example shows how to:
- Initialize the pipeline
- Process a single audio file
- Access metadata fields
- Save results to JSON

### Batch Processing

```bash
python examples/batch_processing.py
```

This example demonstrates:
- Processing multiple files efficiently
- Generating a summary report
- Saving batch results to JSON

### No LLM Usage

```bash
python examples/no_llm_usage.py
```

This example shows:
- Using the pipeline without an API key
- Rule-based metadata generation
- Accessing audio features only

## Output Format

The `example_output.json` file shows the complete structure of the metadata generated by the pipeline. This includes:

- Basic information (title, artist)
- Genre and mood tags
- Detected instruments
- Audio features (tempo, key, energy, valence)
- AI-generated description

## Customization

You can customize the examples by:

1. **Changing models**:
   ```python
   pipeline = MusicTaggerPipeline(
       whisper_model="openai/whisper-large-v3",
       llm_model="gpt-4"
   )
   ```

2. **Processing options**:
   ```python
   metadata = pipeline.process_file(
       "song.mp3",
       transcribe=False,  # Skip transcription
       use_llm=False      # Skip LLM tagging
   )
   ```

3. **Device selection**:
   ```python
   pipeline = MusicTaggerPipeline(device="cuda")  # Use GPU
   ```
